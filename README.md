# Soil Suitability Prediction System

## Introduction

This project predicts soil type and land suitability using Deep Learning.

## Objectives

- Identify soil type
- Predict soil suitability
- Recommend crops
- Improve agricultural planning

## Technologies Used

- Python
- TensorFlow
- OpenCV
- Flask
- NumPy

## Project Structure

```text
soil-suitability-project/
├── data/
├── models/
├── screenshots/
├── docs/
├── src/
└── README.md
```

## Dataset

Download dataset from:
https://drive.google.com/drive/folders/1DcQUoDUt9ehoggHMrJN1RZDn88APctYb?usp=drive_link

data/
├── Black_Soil/
├── Red_Soil/
├── Sandy_Soil/
└── Clay_Soil/

## Installation

```bash
git clone <repository-url>
cd soil-suitability-project

pip install -r requirements.txt
```

## Run Project

```bash
python src/app.py
```
